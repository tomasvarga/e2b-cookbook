# E2B Guide

Run sandbox tools in E2B while OpenAI runs the agent and maintains session state.

Choose a provisioning mode:

- **[Application-managed](#application-managed):** Your application creates and connects the E2B sandbox directly.
- **[Webhook-managed](#webhook-managed):** Deploy a handler that starts or reconnects sandboxes from OpenAI webhooks.

See [Manage Sandbox Lifecycle](./05-manage-sandbox-lifecycle.md) to compare the two modes.

## Before you begin

Set `E2B_API_KEY`, `OPENAI_API_KEY`, and a separate restricted `OPENAI_EXECUTOR_API_KEY`. Keep the application key outside the worker sandbox. The executor key must match the session owner’s organization, project, and user or service account. See [executor authentication](./04-connect-to-a-sandbox.md#authentication).

## Webhook-managed

The [complete example](https://github.com/OpenAI-Early-Access/agents-api-python-preview/tree/main/examples/self_hosted_sandbox/webhook_managed/e2b) includes the handler, deployment script, and cleanup instructions.

1.  Follow the [shared setup](https://github.com/OpenAI-Early-Access/agents-api-python-preview/tree/main/examples/self_hosted_sandbox/webhook_managed#set-up-once) to create an agent and save its returned ID as `OPENAI_AGENT_ID`.
2.  Deploy the E2B controller with the configured `OPENAI_AGENT_ID` and credentials.
3.  Register its URL in **OpenAI project settings → Webhooks** for `agent.session.action_required` and `agent.session.failed`. Install the generated signing secret and redeploy.
4.  Run the shared client to create a session and send input. The webhook handler provisions a separate E2B worker and starts `codex exec-server` inside it.

The example keeps workers running between turns. A later connection request resumes a paused worker or replaces a deleted one. Pausing preserves its files; replacement does not. Workers have a 30-minute running timeout and the controller has a one-hour timeout. Remove its OpenAI webhook when you stop using it.

## Application-managed

In this mode, your application starts the sandbox and connects its executor. Install the dependencies:

```bash
python -m pip install "git+https://github.com/OpenAI-Early-Access/agents-api-python-preview.git" "e2b>=2.45.1"
```

Save the following as `e2b_example.py`. It creates a session, runs a shell command in E2B, and cleans up both resources.

```python
import asyncio
import os
import shlex

from agent_api_sdk import AgentAPISDK
from e2b import AsyncSandbox

async def start_sandbox(environment_id, executor_api_key):
    sandbox = await AsyncSandbox.create(
        timeout=1800,
        envs={"CODEX_API_KEY": executor_api_key},
        network={"allow_public_traffic": False},
    )
    try:
        await sandbox.commands.run(
            "mkdir -p /workspace && npm install -g @openai/codex@alpha",
            user="root",
            timeout=180,
        )
        await sandbox.commands.run(
            shlex.join([
                "codex", "exec-server",
                "--remote", "https://api.openai.com/v1/agents/api",
                "--environment-id", environment_id,
            ]),
            user="root",
            cwd="/workspace",
            background=True,
            timeout=0,
        )
        return sandbox
    except BaseException:
        await sandbox.kill()
        raise

async def main():
    executor_key = os.environ["OPENAI_EXECUTOR_API_KEY"]
    async with AgentAPISDK(timeout=600) as client:
        session = await client.sessions.create(
            agent={"model": "gpt-5.6-sol"},
            environment={"type": "self_hosted", "workspace_directory": "/workspace"},
        )
        sandbox = None
        try:
            sandbox = await start_sandbox(
                session.info.environment.environment_id, executor_key
            )
            completed = False
            async for event in session.stream(input="Run a shell command to print hello."):
                if event.type in {
                    "session.turn.failed", "session.turn.cancelled", "session.failed"
                }:
                    raise RuntimeError(f"Agent failed: {event.type}")
                if event.output_text_delta:
                    print(event.output_text_delta, end="", flush=True)
                if event.type == "session.turn.completed":
                    completed = True
            if not completed:
                raise RuntimeError("Stream ended without a completed turn")
        finally:
            try:
                if sandbox is not None:
                    await sandbox.kill()
            finally:
                await session.delete()

asyncio.run(main())
```

Run `python e2b_example.py` with the three API keys set in your environment. The sandbox has a 30-minute running timeout; `timeout=0` above disables the command timeout, not the sandbox timeout.
